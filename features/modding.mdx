Semistrap includes a modding system that replaces Roblox content files with your own. Both built-in presets (old character sounds, old cursors, custom fonts, old avatar background) and a free-form mods folder are supported. Mods are applied on Roblox launch and removed when Roblox exits.

## How it works

Semistrap manages a local `Modifications` folder. When you launch Roblox through Semistrap, files in this folder are copied over the matching files in the Roblox content directory. On exit, the originals are restored so the base install stays clean.

## Built-in presets

Open **Settings > Mods** and toggle any of these:

- **Old character sounds**: restore the classic walking, jumping, and get-up sounds.
- **Old avatar background**: use the pre-2022 avatar background place.
- **Cursor**: pick between the 2006 and 2013 cursor styles.
- **Emoji font**: swap the emoji font used by the Roblox UI.
- **Custom text font**: choose a `.ttf`, `.otf`, or `.ttc` file to override the default UI font.

## Custom mods (free-form)

For anything not covered by a preset, drop files into the mods folder mirroring Roblox's `content` directory structure.

<Steps>
  <Step title="Open the mods folder">
    In **Settings > Mods**, click **Open mods folder**.
  </Step>
  <Step title="Place your file">
    Copy the replacement asset into the same relative path Roblox uses. For example, to replace a sound at `content\sounds\ouch.mp3`, put your file at `Modifications\content\sounds\ouch.mp3`.
  </Step>
  <Step title="Launch Roblox">
    Start Roblox through Semistrap. The mod is applied automatically.
  </Step>
</Steps>

## Roblox compatibility settings

Semistrap can open the Windows **Compatibility** properties tab for the Roblox Player executable directly from **Settings > Mods**, so you can force compatibility modes or DPI overrides without hunting through Windows Explorer.

<Warning>
  Only replace content assets you own or are licensed to modify. Do not use mods to inject code or interact with the Roblox client beyond asset replacement.
</Warning>
