Semistrap's Discord Rich Presence integration lets your friends see, at a glance, which Roblox game you are currently playing. It runs automatically when activity tracking is on; there is no separate Discord bot or account link to set up.

## Enable Rich Presence

Rich Presence is powered by activity tracking, which is on by default.

<Steps>
  <Step title="Open Semistrap">
    Launch Semistrap from the Start Menu.
  </Step>
  <Step title="Go to Integrations">
    Open **Settings > Integrations**.
  </Step>
  <Step title="Confirm activity tracking is on">
    Make sure **Enable activity tracking** is toggled on. Without it, Rich Presence has nothing to display.
  </Step>
  <Step title="Optionally show server region">
    Turn on **Query server location** to include the server region on your Discord profile.
  </Step>
</Steps>

## What friends see

When Rich Presence is active and you launch a Roblox game, your Discord profile shows:

- The game you are playing
- Optional server region (if **Query server location** is enabled)
- Elapsed play time

When Roblox is not running, Semistrap shows an idle presence ("Using Semistrap"). Rich Presence stops when you close Semistrap.

<Note>
  Discord must be running on the same machine before you launch Roblox. If Rich Presence does not appear, see [Discord Rich Presence not working](/troubleshooting#discord-rich-presence-not-working).
</Note>
