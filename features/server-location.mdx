Semistrap includes an activity tracker that detects the Roblox server you connect to and can display its geographic region. This is useful for understanding latency, verifying region routing, or knowing where your matches are hosted.

## What it shows

For each Roblox session, Semistrap can display the region of the connected server. When **Show server details** is enabled, the region is also included in your Discord Rich Presence.

The location lookup is provided by [ipinfo.io](https://ipinfo.io).

## Enable server details

<Steps>
  <Step title="Open Integrations">
    Go to **Settings > Integrations**.
  </Step>
  <Step title="Enable activity tracking">
    Turn on **Activity tracking** if it is off. Server-details lookups require it.
  </Step>
  <Step title="Enable Show server details">
    Toggle **Show server details** on.
  </Step>
</Steps>

## Privacy

Only the Roblox server's public IP is queried. Semistrap does not share your own IP or account information with third parties.

<Info>
  Location lookups happen on-demand when you join a game. If your network blocks ipinfo.io, the region field stays blank and Semistrap continues to function normally.
</Info>
