The bootstrapper dialog is the window Roblox shows while it updates and launches. Semistrap lets you pick from historical styles, use its own Fluent dialog, or design a fully custom one with the built-in editor.

## Built-in dialog styles

Available under **Settings > Bootstrapper > Dialog**:

- **VistaDialog**: the Windows Vista/7-era style.
- **LegacyDialog2008** and **LegacyDialog2011**: recreations of the older Roblox bootstrappers.
- **ProgressDialog**: minimal progress bar.
- **ClassicFluentDialog**: the previous Fluent design.
- **ByfronDialog**: matches the modern Byfron-era Roblox bootstrapper.
- **Semistrap** (default): the current Fluent design.
- **FluentAeroDialog**: Fluent with Windows Aero-like transparency.
- **CustomDialog**: renders a custom theme you have created.

Click **Preview** on the settings page to see the chosen dialog without launching Roblox.

## Bootstrapper icon and title

You can also change:

- **Icon**: pick a Roblox-era icon (2008, 2011, 2015 early/late, 2017, 2019, 2022) or Semistrap's own icon, or load a `.ico` file from disk.
- **Title**: the text shown in the dialog window title bar.

## Custom themes

Selecting **CustomDialog** unlocks the custom themes list. From there you can:

- **Add** a new theme (name it and choose a base template).
- **Edit** the current theme in a visual editor for backgrounds, colors, fonts, and layout.
- **Rename**, **Delete**, or **Export** a theme as a `.zip` file to share.

Themes are stored in your custom themes folder as `Theme.xml` plus any referenced image assets.

<Tip>
  Export a theme to share it with friends. To import, unzip it into a new folder inside the custom themes directory.
</Tip>
