---

Semistrap exposes graphics and UI options that would otherwise require editing Roblox's client settings by hand. Adjustments apply the next time you launch Roblox through Semistrap.

## What you can change

- **Graphics quality**: force a specific quality level rather than letting Roblox auto-detect
- **Rendering mode**: pick a preferred graphics API when supported
- **UI scale**: adjust the size of Roblox's in-game interface
- **FPS unlocker toggle**: enable an unlocked frame rate if your hardware supports it

## Change graphics settings

<Steps>
  <Step title="Open Semistrap">
    Launch it from the Start Menu.
  </Step>
  <Step title="Go to Bootstrapper settings">
    Open **Settings > Bootstrapper**.
  </Step>
  <Step title="Adjust and save">
    Change the graphics options you want and save. The next Roblox launch through Semistrap picks up the new values.
  </Step>
</Steps>

<Tip>
  If a game feels unstable after changing graphics settings, restore defaults from the same menu and relaunch.
</Tip>
