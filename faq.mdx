Answers to the questions most Semistrap users ask before installing.

<AccordionGroup>
  <Accordion title="Is Semistrap malware?">
    No. Semistrap is fully open source; the code is on [GitHub](https://github.com/set-semi/Semistrap) for anyone to audit. It would be impossible to slip malicious code into releases without users noticing. Just make sure you download it from an official source.
  </Accordion>

  <Accordion title="Can using Semistrap get me banned?">
    It should not. Semistrap does not interact with the Roblox client the way exploits do; it is a bootstrapper replacement, not an injector or a cheat.
  </Accordion>

  <Accordion title="What are the official download sources?">
    Only two: this [GitHub repository](https://github.com/set-semi/Semistrap) and [semistrap.vercel.app](https://semistrap.vercel.app). Any other site offering Semistrap downloads is not affiliated with the project.
  </Accordion>

  <Accordion title="Does Semistrap work on macOS or Linux?">
    No. Semistrap is Windows-only.
  </Accordion>

  <Accordion title="Does Semistrap collect analytics?">
    Semistrap is designed to keep third-party network calls minimal and configurable. Server-location lookups (via ipinfo.io) and Discord Rich Presence can each be turned off from **Settings > Integrations**.
  </Accordion>
</AccordionGroup>
