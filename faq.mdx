Short answers to the questions people ask most often about Semistrap. See [Troubleshooting](/troubleshooting) for fix-oriented issues.

<AccordionGroup>
  <Accordion title="Is Semistrap malware?">
    No. Semistrap is open source; the full source is in the [GitHub repository](https://github.com/set-semi/Semistrap) and every release is built from it. It is not possible to slip malicious code into an official release without it being visible in the source. Only download Semistrap from the official sources listed below.
  </Accordion>

  <Accordion title="Can using Semistrap get me banned from Roblox?">
    It should not. Semistrap replaces the standard Roblox bootstrapper and manages content-file mods; it does not interact with the running Roblox client the way exploits do. That said, use it at your own risk and only apply mods to your own content.
  </Accordion>

  <Accordion title="What are the official download sources?">
    Only two:

    - [github.com/set-semi/Semistrap](https://github.com/set-semi/Semistrap)
    - [semistrap.vercel.app](https://semistrap.vercel.app)

    Any other website offering Semistrap downloads is unofficial.
  </Accordion>

  <Accordion title="Does Semistrap work on macOS or Linux?">
    No. Semistrap is Windows-only. Roblox's own Windows client is required.
  </Accordion>

  <Accordion title="Does Semistrap require .NET?">
    Yes: the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). If it is missing, the installer prompts you to install it.
  </Accordion>

  <Accordion title="Do I need to keep Semistrap open while playing?">
    Yes if you want Discord Rich Presence, activity tracking, or custom integrations to run. Semistrap detects Roblox activity in the background while it is open.
  </Accordion>

  <Accordion title="Where does Semistrap store its config?">
    In your local Semistrap app data folder. Use **Settings > Semistrap > Export data** to bundle it into a zip.
  </Accordion>

  <Accordion title="How do I report a bug?">
    Open an [issue on GitHub](https://github.com/set-semi/Semistrap/issues) with an exported support bundle attached, or ask in the [Discord server](https://discord.gg/s3QW8b6PUf).
  </Accordion>
</AccordionGroup>
