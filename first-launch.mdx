The Semistrap installer registers Semistrap as the Roblox bootstrapper and creates shortcuts. The menu can be reopened anytime from the Start Menu or via the `-settings` argument.

## What the installer does

- Registers Semistrap as the default Roblox launcher for `roblox-player:` and `roblox-studio:` URIs.
- Creates a Start Menu shortcut for the Semistrap menu.
- Optionally creates desktop shortcuts (Roblox Player, Roblox Studio, Semistrap Settings). See [Shortcuts settings](/settings/shortcuts).
- Prepares the mods folder and config directory.

## Reopening the menu

After install, open Semistrap from the **Start Menu**, or run the executable with `-settings` to jump straight to the settings window.

<Tip>
  Pin Semistrap to the Start Menu or taskbar for quick access.
</Tip>

## Command-line launch modes

Semistrap accepts these launch arguments:

- `-player`: launch Roblox Player
- `-studio`: launch Roblox Studio
- `-settings`: open the settings window
- `-menu`: open the launch menu

These are the same arguments the built-in shortcuts use, and you can pass them to any custom shortcut you create.
