The first time you run Semistrap, a setup wizard collects your preferences before installing. This page describes what to expect and how to reopen the menu later.

## Setup wizard

The wizard covers the basics:

- Where to install Semistrap
- Whether to enable Discord Rich Presence
- Which mods and content overrides to apply
- Graphics and UI defaults for Roblox

Every choice can be changed later from the Semistrap menu; nothing here is permanent.

## Reopening the menu

After install, Semistrap is added to your **Start Menu**. Open it any time to:

- Reconfigure preferences
- Toggle integrations
- Apply new mods
- Repair or reinstall

<Tip>
  Pin Semistrap to the Start Menu or taskbar for quick access to its settings.
</Tip>
