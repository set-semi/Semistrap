Semistrap runs on Windows and requires the .NET 10 Desktop Runtime. Installation takes a couple of minutes: download the release, run it, and configure a few preferences.

## Requirements

- **Windows** (Semistrap is Windows-only).
- [**.NET 10 Desktop Runtime**](https://dotnet.microsoft.com/download/dotnet/10.0). If it is missing, Semistrap prompts you to install it on first launch. Install .NET first, then install Semistrap.

## Install Semistrap

<Steps>
  <Step title="Download the latest release">
    Go to [github.com/set-semi/Semistrap/releases/latest](https://github.com/set-semi/Semistrap/releases/latest) and download the installer.

    <Warning>
      Only download from the [GitHub releases page](https://github.com/set-semi/Semistrap/releases) or [semistrap.vercel.app](https://semistrap.vercel.app). Any other site is unofficial.
    </Warning>
  </Step>
  <Step title="Run the installer">
    Double-click the downloaded file.
  </Step>
  <Step title="Dismiss SmartScreen (if it appears)">
    Windows SmartScreen may show a warning because Semistrap is not a widely-recognized publisher. Click **More info > Run anyway**. This does not mean Semistrap is malicious; see [Is this malware?](/faq).
  </Step>
  <Step title="Configure preferences">
    Choose your bootstrapper style, integrations, and shortcuts. You can change any of these later in the settings menu.
  </Step>
  <Step title="Install">
    Click **Install**. Semistrap registers itself as the Roblox launcher and adds a Start Menu shortcut.
  </Step>
</Steps>

## Reopen the menu

After install, launch Semistrap from the Start Menu whenever you want to change settings. See [First launch](/first-launch) for what to expect.

## Uninstall

To uninstall, open Semistrap and use its uninstall option, or remove it from **Windows Settings > Apps**.
