The **Appearance** page controls how both the Semistrap menu and the bootstrapper dialog look.

## Menu

- **Theme**: `Default` (follows Windows), `Light`, or `Dark`. Applies immediately to the settings window.
- **Language**: pick a UI language from the supported locales list.

## Bootstrapper dialog

- **Dialog style**: choose from historical Roblox styles, Semistrap's Fluent dialog, or a custom theme. See [Custom bootstrapper](/features/custom-bootstrapper) for the full list.
- **Preview**: open the selected dialog with sample text so you can see it before launching Roblox.
- **Icon**: pick a Roblox-era icon or `Custom` and browse to a `.ico` file.
- **Title**: the window title shown on the bootstrapper dialog.

## Custom themes

The **Custom themes** section is expanded only when **Dialog style** is set to `Custom`. Use it to:

- **Add** a new theme.
- **Rename**, **Delete**, or **Export** the selected theme.
- **Edit** the theme in the visual bootstrapper editor.

See [Custom bootstrapper](/features/custom-bootstrapper) for a walkthrough.
