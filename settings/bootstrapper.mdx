The **Bootstrapper** page controls how Semistrap prepares and launches Roblox itself.

## Launch behavior

- **Confirm launches**: show a confirmation dialog before Roblox starts. Useful if you launch from browser links and want a chance to cancel.

## Updates

- **Background updates**: install Roblox updates in the background between sessions instead of blocking the next launch.

## Reinstall Roblox

- **Force Roblox reinstallation**: on the next launch, Semistrap wipes and reinstalls Roblox from scratch.

<Note>
  If neither Roblox Player nor Studio is installed, this option is on and cannot be turned off until Roblox is installed successfully.
</Note>

Use this after a broken update or when troubleshooting install corruption. See [Troubleshooting](/troubleshooting) for related fixes.
