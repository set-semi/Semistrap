The **Integrations** page controls Semistrap's activity tracker and everything built on top of it, plus custom applications that launch when Roblox does.

## Activity tracking

- **Activity tracking**: master switch. When off, Semistrap does not read the Roblox log to detect games and servers, and every dependent feature is disabled.

## Discord Rich Presence

Requires activity tracking.

- **Discord Rich Presence**: enable or disable the built-in RPC integration.
- **Hide RPC buttons**: hide the join and other buttons that games can add to the presence.
- **Show account on Rich Presence**: include the Roblox username you are playing as.
- **Show server details**: include the connected server's region on your Discord profile.

See [Discord Rich Presence](/features/discord-rich-presence) and [Server location](/features/server-location) for details.

## Custom integrations

Custom integrations are external programs that Semistrap launches alongside Roblox.

<Steps>
  <Step title="Click Add">
    A new integration entry is created with a default name.
  </Step>
  <Step title="Browse to the executable">
    Click **Browse** and pick the program. The integration's name defaults to the file name.
  </Step>
  <Step title="Set launch arguments">
    Enter any command-line arguments the program needs in the **Launch args** field.
  </Step>
  <Step title="Choose whether it auto-closes">
    Enable **Auto close** to have Semistrap terminate the program when Roblox exits.
  </Step>
</Steps>

Use **Delete** to remove the currently selected integration.

<Tip>
  Custom integrations are a good way to run stream overlays, hotkey managers, or capture tools only while Roblox is active.
</Tip>
