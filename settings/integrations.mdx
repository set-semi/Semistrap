The **Integrations** tab controls how Semistrap talks to third-party services. Every integration can be turned off independently.

## Available integrations

- **Discord Rich Presence**: show the Roblox game you are playing on Discord. See [Discord Rich Presence](/features/discord-rich-presence).
- **Server location (ipinfo.io)**: display the geographic location of the Roblox server. See [Server Location](/features/server-location).

## Rich Presence display options

When Discord Rich Presence is on, you can toggle:

- Game name
- Server region
- Elapsed play time

## Turn an integration off

<Steps>
  <Step title="Open Integrations">
    In Semistrap, go to **Settings > Integrations**.
  </Step>
  <Step title="Toggle the integration">
    Switch the integration off. Semistrap stops making the associated network requests immediately.
  </Step>
</Steps>
