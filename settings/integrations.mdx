The **Integrations** page controls Semistrap's activity tracker (which powers Discord Rich Presence) and lets you register custom applications that launch when Roblox does.

## Activity tracking

- **Enable activity tracking**: master switch. When off, Semistrap does not read the Roblox log to detect games and servers, and Discord Rich Presence has nothing to display.
- **Query server location**: look up the connected server's region via [ipinfo.io](https://ipinfo.io) and include it in Discord Rich Presence. Requires activity tracking.

See [Discord Rich Presence](/features/discord-rich-presence) and [Server location](/features/server-location) for what these enable.

## Custom integrations

Custom integrations are external programs that Semistrap launches alongside Roblox.

<Steps>
  <Step title="Click New">
    A new integration entry is created with a default name.
  </Step>
  <Step title="Browse to the executable">
    Click **Browse** and pick the program. The integration's name defaults to the file name; you can rename it in the **Name** field.
  </Step>
  <Step title="Set launch arguments">
    Enter any command-line arguments the program needs in the **Launch args** field.
  </Step>
  <Step title="Choose whether it auto-closes">
    Enable **Auto close** to have Semistrap terminate the program when Roblox exits.
  </Step>
</Steps>

Use **Delete** to remove the currently selected integration.

<Tip>
  Custom integrations are a good way to run stream overlays, hotkey managers, or capture tools only while Roblox is active.
</Tip>
