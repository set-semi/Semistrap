The **Shortcuts** page manages Windows shortcuts for Semistrap and the Roblox launch modes.

## Available shortcuts

Toggle each shortcut on to create it, or off to remove it:

- **Desktop icon**: Semistrap main app on the desktop.
- **Start Menu icon**: Semistrap in the Windows Start Menu.
- **Roblox Player**: desktop shortcut that runs Semistrap with `-player`.
- **Roblox Studio**: desktop shortcut that runs Semistrap with `-studio`. Only visible when Studio is installed.
- **Settings**: desktop shortcut that opens Semistrap's settings window directly (`-settings`).

## Extract icons

The **Extract icons** action writes the Semistrap application icons as standalone `.ico` files. Use these when creating your own custom shortcuts or Start Menu tiles.

<Tip>
  If a shortcut points at an old Semistrap install after moving the executable, toggle it off and back on to recreate it against the current path.
</Tip>
